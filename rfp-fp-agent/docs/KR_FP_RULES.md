## 3. 개발비 산정 체인

```
보정전 개발원가 = 총 기능점수 × 기능점수당 단가 × Σ(단계별 기능점수 가중치)
보정후 개발원가 = 보정전 개발원가 × 규모 × 연계복잡성 × 성능요구수준 × 운영환경호환성 × 보안성수준
소프트웨어 개발비 = 보정후 개발원가 + 이윤(개발원가의 25% 이내) + 직접경비
```

- **표 3-21 기능점수당 단가**: 553,114원 (2020년판) / **605,784원 (2025년판 원문 확인)**
- **표 3-22 단계별 가중치**: 분석 19.0% · 설계 24.0% · 구현 32.0% · 시험 25.0% (합 100%)
  - 2025년판 단계별 FP단가: 분석 115,099원 · 설계 145,388원 · 구현 193,851원 · 시험 151,446원
  - 2025년판 신설 — 단계별 발주 구분: **설계사업 28.1%(170,225원) / 구축사업 71.9%(435,559원)**
- **이윤**: 국가계약법 시행규칙 제8조 제2항 제2호 — 개발원가의 25% 초과 불가
- **국내 가이드는 VAF(GSC 14개)를 사용하지 않는다.**

### 표 3-23 규모 보정계수
```
규모 보정계수 = 0.4057 × (ln(기능점수) − 7.1978)² + 0.8878
단, 500FP 미만 → 1.2800,  3,000FP 초과 → 1.1530
```
검증: 공식은 FP=500 에서 1.2800, FP=3,000 에서 1.1530 에 수렴한다(테스트 확인).

### 반올림 규칙 (가이드에 명시 없음 — 역산 결과)

> **보정계수를 하나씩 순차적으로 곱하며, 매 단계 원 단위 반올림(ROUND_HALF_EVEN).**

| 가설 | 2020년판 | 2025년판 |
|---|---|---|
| 결합 곱 후 1회 절사 | 53,173,990 ✓ | 58,237,456 ✕ |
| 결합 곱 후 1회 반올림 | 53,173,991 ✕ | 58,237,457 ✓ |
| **순차 곱 + 매 단계 HALF_EVEN** | **✓** | **✓** |

개정판 1종만으로 검증하면 잘못된 규칙(절사)에 도달한다. **발주기관 공식 Excel 과의 대조는 아직 하지 않았다** — 도입 전 필수.

## 8. 기타 관례
- 경계 밖 데이터 조회: 통상 **EIF 1개 + EQ(또는 EO) 1개**
- 공통모듈: 원칙적으로 **1개 기능으로 1회만** 산정 (단, 사용자 요구로 DET 이 달라지면 별도)
- 모바일 버전: 동일 경계면 논리파일 재식별 없음, 화면 DET 변경 시 트랜잭션만 별도 산정
- 데이터 기능 식별(사업 초기): **트랜잭션 기능으로부터 역추론** (등록/수정/삭제가 있으면 해당 엔티티 필요)
